# 이 프로젝트의 파이썬 의존성 목록
#
# 사실 이 프로젝트는 외부 패키지를 하나도 쓰지 않는다.
# HTTP 요청은 표준 라이브러리 urllib.request 로, JSON 처리는 json 으로 한다.
# 의존성이 적다는 사실 자체가 장점이다(설치 실패·버전 충돌 위험이 없다).
#
# Vercel 은 이 파일이 있어야 파이썬 런타임으로 함수를 빌드한다.
# 나중에 SDK(예: google-genai)를 쓰게 되면 여기에 추가하면 된다.
# 현재는 provider 레지스트리(api/_lib/ai.py)에서 호출부만 갈아끼운다.
#
# 예시:
# google-genai==1.0.0
# openai==1.40.0
