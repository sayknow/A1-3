실제 원천 서버의 공고 · AI 근거 설명

내 조건에 맞는 원격 구직 공고를
AI가 골라 이유와 함께 알려드립니다

공고 사이트를 한 곳씩 돌아다니며 걸러내는 시간을 줄이는 것이 목표입니다. 직무·기술스택·경력·희망 금여를 입력하면, 실제로 올라와 있는 원격 공고 중 조건에 맞는 것만 골라 왜 추천하는지까지 설명해 드립니다.

추천 받으러 가기 공고 먼저 둘러보기

무엇이 다른가

공고 더미가 아니라, 실제 데이터 위에서 동작합니다.

1. 실제로 올라온 공고만

샘플 데이터를 하드코딩한 것이 아니라, 공개된 원천 API 서버 3곳에서 실시간으로 수집한 공고를 씁니다. 각 카드의 출처 배지로 어디서 왔는지 표시합니다.

2. 이유를 함께 알려줌

점수만 보여주는 추천은 신뢰가 어렵습니다. 각 공고마다 매칭 근거와 아쉬운 점, 다음에 할 행동을 함께 제시합니다.

3. 실패해도 안 죽음

원천 API 장애, AI 응답 지연, 빈 입력 같은 상황을 모두 처리했습니다. 서비스가 멈추지 않고, 대신 왜 안 되는지 안내 메시지를 보여줍니다.

사용 흐름

입력 → 수집 → 매칭 → AI 설명 → 결과

단계설명담당
1. 조건 입력 직무, 기술스택, 경력 수준, 최소 희망 금여를 폼에 입력 프론트엔드 (HTML/JS)
2. 공고 수집 3개 원천 API 호출 → 필드 이름이 다르니 공통 형태로 정규화 → 중복 제거 서버 (Python)
3. 사전 매칭 키워드 일치로 후보를 상위 8건으로 좁힘 (AI 비용 절감) 서버 (Python)
4. AI 판정 후보 공고를 AI에 보내 적합도·근거·아쉬운 점·행동을 생성 서버 (Python → AI)
5. 결과 표시 점수 순으로 정렬해 카드 형태로 렌더링 프론트엔드 (JS)

데이터 출처

모두 API 키가 필요 없는 공개 엔드포인트를 사용합니다.

각 출처의 이용 약관에 따라 소스 표기를 함께 제공합니다. 공고 데이터는 원천 서버에 등록된 내용을 그대로 옮긴 것이며, JobFit는 공고 내용을 수정하거나 보증하지 않습니다.

기술 스택

프론트엔드

순수 HTML / CSS / JavaScript. 프레임워크·빌드 도구 없이 동작합니다.

백엔드

Vercel Serverless Functions (Python). api/ 폴더의 엔드포인트가 각자 독립 함수로 실행됩니다.

AI

Google Gemini API (gemini-3.8-flash). 제공자는 환경변수만 바꾸면 교체되며,urllib 표준 라이브러리만 사용합니다. 키는 Vercel 환경변수로만 주입되어 브라우저에 노출되지 않습니다.
